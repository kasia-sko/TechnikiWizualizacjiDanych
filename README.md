## Data Visualisation Techniques

In this repository, you can find files from the course Data Visualisation Techniques during the third semester (winter 2024/2025) at WUT. During this course, we used **R** and **Python** and worked in RStudio and Jupyter Notebook.

There are two main projects:
* [Poster](https://github.com/kasia-sko/TechnikiWizualizacjiDanych/tree/main/project_1) - a poster about organ transplants
* [Shiny App](https://github.com/kasia-sko/TechnikiWizualizacjiDanych/tree/main/project_2) - a Shiny app about our daily activities and phone usage. 

Additionally, you can find the [homeworks](https://github.com/kasia-sko/TechnikiWizualizacjiDanych/tree/main/homeworks).
